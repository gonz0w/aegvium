# Git and local review

Use codex/ branches, signed Conventional Commits and author DCO sign-offs; annotated release tags are signed. Run make verify locally. No Actions, hosted/self-hosted runners or status-publishing substitute. PR evidence records candidate/base/tree identities, signature and DCO results, commands, actual outcomes and relevant native evidence. Leave PRs open.

Match EdgeWall and BootWeave foundation conventions. DNS reference path was unavailable at setup; reconcile when located. GitHub issues and the existing homelab project will track live work once remote authentication/setup is available. Ruleset JSON is a template until applied and read back; no remote protections are claimed.

Runtime dependencies require a license/provenance/security ADR with pinned revisions, update and removal paths. Release artifacts need reproducibility, native acceptance and maintainer authorization.
