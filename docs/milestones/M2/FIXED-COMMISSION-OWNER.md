the coordinator nor placement helper has been executed or qualified. The default
builder entry refuses; there is no force flag or serialized freshness receipt.

then the one fixed no-NIC/no-reboot installer child and all retained input/target
descriptors. Source originates from an actual signed local Git export, compiler
outputs from the pinned local tool, and stock ISO authentication using the
existing release-verification policy. This is candidate build
lineage, not release authenticity, production admission or execution permission.

file fsync and directory fsync, then reports the exact observed generation and
descriptor/payload digests through the actual owned VM console. This observation
alone creates no image lifetime or launch authority. On any partial state/fault,
normal handoff is forbidden; existing/user data is never repaired or deleted.

inherited fdset reference. Exclusive terminal wait, owned channel closure,
matching target identity and successful local input-handle closure precede its
local prepared-candidate result. It retains the actual FD and exact paired
snapshot; there is no completed frontend-owner handoff or production admission.
It never starts the installed target. Root/template handlers must not replace
that owner with a path/hash/Boolean/callback or reconstruct it from observations.
