# Normal inspector termination and durable settlement

Source only, under the already approved ADR0014 normal-clean semantics. Native
qualification and Draft126's validation pause remain. Both default and explicit
source supervisor entries refuse77 before signal setup, storage or launch, using
an immutable false gate. No flag, config, receipt or callback can enable it.

The same private native owner that captures the actual fork and exclusively
waits for that exact child now has one zero-input settlement call. It requires
its own matching terminal status (or actual negative-fork NoChild), successful
once-only closure of every locally owned construction/channel handle and no
lost/ambiguous physical ownership. Controller views, ACK, Stop, supplied PIDs,
empty slots, hashes or parsed checkpoint data cannot create these private facts.
Operational use still requires qualified no-descendant/no-export construction.

Only then does its one fixed private storage bridge run. It retains the original
checkpoint descriptor and uninterrupted EX lock, saved original device/inode and
canonical committed U128. Re-traverse the fixed protected namespace, revalidate
current opened/named metadata and original inode, read exact U(g) and compare
with privately retained committed bytes; revalidate again before writing. Encode
C(g) with the SAME watermark, one exact128-byte write, one fsync, one exact readback,
then original-inode/named metadata checks and once-close of the new directory.
Keep the checkpoint/exclusion until S exits. No create, rename, truncate,
checkpoint reopen, reset, unlock, generation advance or repair is added.

All storage work follows actual terminal wait and local closure. It cannot delay
active stop/escalation/wait. Late but physically proved cleanup may settle C(g),
while missed/unverifiable timing, clock/control faults and failed service status
remain failures. C is neither a four-second pass, S-exit receipt, Ready nor an
allow verdict. An uncertain write/sync/readback/inode/close never reports known
clean and is not retried; C may have reached storage after a failed operation.

The approved [required security-record source](SECURITY-RECORDS.md) now uses this
same guard and retained EX: its terminal-boundary record and any oldest sealed
segment rotation must commit before the C write. A record failure refuses normal
settlement. Neither segment contents nor successful rotation can create the
physical facts required to reach this path.

This closes the source history step needed after normal known retirement. It
does not automatically restart or prepare the next pair: the next launch still
needs genuinely fresh paired generation g+1 and its real intent/snapshot handoff.
The maximum generation cannot wrap. Supervisor-loss cleanup/cold recovery remains
unselected; free flock, operator assertion, assumed reboot or PID adoption does
not repair U. Stopped-service maintenance is unchanged; hot updates unsupported.
