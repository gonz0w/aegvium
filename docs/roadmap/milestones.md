# Roadmap

M0: local repository, conventions, proposed requirements/design/tests; remote setup pending authentication.
M1: disposable native stack feasibility, integration selection and dependency ADR.
M2: bounded inline inspection and deny-by-default routing after reviewed design.
M3: rules tuning, operational limits, logs, update/recovery and native qualification.
M4: BootWeave integration when its contract is available; optional CrowdSec with separate reviewed design.

Each phase needs scoped PRD/EDD/Test Design and observed acceptance evidence. Component merge does not close a phase.
